# WEEK 1-2 : Attention Is All You Need

## 1. 서론 및 배경
기존의 시퀀스 모델링 및 변환 작업(기계 번역 등)은 주로 복잡한 순환 신경망(RNN)이나 합성곱 신경망(CNN)을 기반으로 한 인코더-디코더 구조를 사용

RNN은 이전 상태의 계산이 완료되어야 다음 단계를 진행할 수 있는 순차적인 특성 때문에 학습 시 병렬화가 불가능하며, 시퀀스가 길어질수록 메모리 제약과 장거리 의존성 학습에 어려움

본 논문 → 이러한 제약을 극복하기 위해 재귀나 합성곱을 완전히 배제하고 오직 어텐션 메커니즘에만 의존하는 새로운 아키텍처인 트랜스포머 제안!

## 2. 모델 아키텍처**

 트랜스포머는 인코더와 디코더가 각각 6개씩 쌓인 구조

인코더의 각 층은 멀티 헤드 셀프 어텐션과 완전 연결 피드포워드 네트워크라는 두 개의 서브 층으로 구성되며, 각 서브 층 뒤에는 잔차 연결(residual connection)과 레이어 정규화가 적용

디코더는 인코더의 구조에 더해 인코더의 출력에 어텐션을 수행하는 세 번째 서브 층을 포함하며, 자기 회귀적 특성을 유지하기 위해 현재 위치보다 뒤에 있는 단어를 보지 못하게 하는 '마스킹(Masking)' 기법이 적용된 어텐션을 사용

## 3. 핵심 메커니즘 **(추가 공부 필요함)**

- 스케일드 닷-프로덕트 어텐션(Scaled Dot-Product Attention)
    
    :쿼리(Query)와 키(Key)의 점곱을 구한 뒤 스케일링을 거쳐 가중치를 산출하고 이를 값(Value)에 적용
    
- 멀티 헤드 어텐션(Multi-Head Attention)
    
    : 어텐션을 여러 번 병렬로 수행 → 모델이 서로 다른 위치의 다양한 정보에 동시에 집중
    
- 포지셔널 인코딩(Positional Encoding)
    
    : 사인/코사인 함수 기반의 위치 벡터 → 순서 정보 제공
    

## 4. 셀프 어텐션의 장점

- 층당 전체 계산 복잡도가 낮음
- 병렬화 가능
- 네트워크 내에서 임의의 두 위치 사이의 경로 길이가 일정 → 멀리 떨어진 단어 사이의 관계(장거리 의존성) 학습 용이

## 5. 실험 및 결과

- 영어-프랑스어 작업: 41.8 BLEU라는 우수한 성적
